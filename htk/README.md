# HTK tools

`htk list`, `htk status`, `htk mdview`, `htk github-prs` and `htk name-session`
are the commands included here. The GitHub viewer uses ordinary `gh` access;
the other viewers accept local files. Run `htk COMMAND --help` for usage.

Use the parent folder's `setup.sh` for installation. Detailed component notes
live under `libexec/`. Runtime downloads use public release sources.
