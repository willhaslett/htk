# Herdr keyboard helpers

Presets in `presets/` provide layered H/J/K/L navigation and Ghostty forwarding.
The copied helpers preserve sessions while moving panes and workspace groups.
See `libexec/herdr_controls/README.md` for movement and close protections.

Use the parent folder's `setup.sh` to install commands, then follow its README
to apply application configuration and link the read-only shortcut popup.
